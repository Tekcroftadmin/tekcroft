2. Fix These on the Website Before Launch
Google only trusts schema that matches what visitors can see on the page. I found these mismatches on the current site:
Footer contact details are different. The footer currently shows 1200 Brickell Avenue, Miami, FL 33131, hello@tekcroft.com and +1 (800) 555-0142. Update the footer, Contact page and the “Book a Free Call” section to the Sheridan, Wyoming address, admin@tekcroft.com and +1 (800) 555-3100.
Placeholder text in the home page FAQ. Question 2 contains “We will add the pricing range here.” and Question 6 contains “Add placeholder.” Remove these. The FAQ schema in this file uses the cleaned answers, so update the page text to match the schema exactly.
Years in business mismatch. The footer says “since 2013” but a home page widget says “28+ Years”. Pick one true number. The schema uses foundingDate 2013.
Logo URL. The schemas use https://www.tekcroft.com/logo.png. Replace it with your real logo file path (square PNG/SVG, at least 112×112 px, ideally 512×512 px).
Domain. The site’s canonical tag already points to https://www.tekcroft.com, so every schema uses that domain. If you launch on a different domain, find-and-replace “https://www.tekcroft.com” in all code.
Service page descriptions. I could not open the inner service pages, so each Service schema has a written description. Replace each one with that page’s own meta description so they match.

Schemas deliberately NOT added (and why)
LocalBusiness / ProfessionalService: this type is meant for a physical location customers visit. If the Sheridan address is a registered-agent or virtual office, using LocalBusiness can cause problems with Google, so the address goes inside Organization instead. If you have a real office customers visit, tell me and I will add it.
AggregateRating / Review (4.8/5 across 320+ reviews): Google does not show review stars for reviews a business shows about itself on its own site, and marking them up can trigger a manual action. Keep the reviews visible on the page; just don’t mark them up.
Sitelinks SearchAction: the site has no search box, and Google retired the sitelinks search box feature, so it is not needed.
